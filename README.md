# 练有数

练有数是一款免费的离线 Android 健身与体重记录应用。适用于 Android 8.0 及以上设备。

[下载最新版 APK](https://github.com/unpiom/lianyoushu/releases/latest)

## 功能

- **体重**支持当天记录、历史补记、7 天均重和 30 天曲线。当天记录需要二次确认，确认后锁定。设置目标后，累计至少 4 条记录且跨度达到 7 天，即可根据近期下降趋势估算日期。
- **训练**可按星期安排每周重复的训练计划，并设置时长、动作和组数。开练后可逐组记录重量与次数，自动开始组间倒计时，并查看同一动作的上次记录。
- **步数**可手动录入或补记，设置每日目标，并查看来源和 7 天日均。支持 Health Connect 的 Android 14 及以上设备可授权读取系统步数。
- **复盘**可用月历查看训练记录和逐组数据。周报汇总实际训练时长，并比较相邻两段 7 天均重。腰围可单独记录和查看趋势。

## 数据与权限

体重、腰围、训练计划、打卡和手动步数保存在手机的应用私有存储中，卸载应用会清除这些数据。应用可离线使用。

从 1.0 覆盖升级后，已有体重记录视为已确认。新版对当天体重进行确认锁定，历史日期新补录的条目可以修正。

连接 Health Connect 时，练有数申请读取步数权限，用它显示最近 7 天的本机系统步数。系统步数由 Health Connect 储存和管理。手动录入优先用于同日步数的显示。可以在手机系统设置里撤回权限。

## 本地构建

Windows 需要 PowerShell 7、JDK 17 或更新版本、Android SDK Platform 35 和 Build Tools 35.0.1。设置 `JAVA_HOME` 和 `ANDROID_HOME` 后，在仓库目录运行下列命令。

```powershell
pwsh -NoProfile -File .\build.ps1
```

构建产物为仓库目录下的 `练有数.apk`。构建脚本在 `.build/signing` 保存本地签名材料。使用相同签名的 APK 即可覆盖更新，保留应用数据。
