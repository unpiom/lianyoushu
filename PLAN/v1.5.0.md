# 练有数 v1.5.0

## 改动

- 训练页直接显示今日训练和可续练草稿，移除本周进度卡片与日期栏。「临时训练」放在「新建计划」右上角，「重置计划」放在每周计划底部。
- 临时训练填写名称后即可开练。名称词条可再次点选、改名和移除。临时训练计入复盘的训练次数和时长。
- 计划训练和临时训练支持逐组计时。完成本组后开始休息倒计时，下一组手动开始。复盘可查看每组用时，旧记录缺少用时显示「未计时」。点选月历日期后更新下方详情，月历停在原位置。
- 可从训练页底部开启立体桌面悬浮球。闲置 10 秒或拖到屏幕左、右侧时自动贴边，点击后唤回训练菜单。
- 达标预测每天默认选中当前范围内的最远日期，手动选择当天有效。
- 正式版版本号为 `1.5.0`，版本代码为 `13`，并更新应用内公告。

## 验证

- 通过离线构建和 Android Lint 检查。核对 APK 包名、版本、文件对齐与签名，证书与 `v1.4.1` 一致。APK 内置示例计划与单独发布的 JSON 相同。
- 检查版本 5 数据库的迁移、旧逐组记录的读取、草稿续练、临时训练和逐组计时。
- 检查悬浮球左右侧拖动贴边、拉出逻辑，以及达标预测的 7、14、56 天上限、当日手选和跨日重置。
- 覆盖安装、桌面悬浮球手势和跨午夜刷新待真机验证。
